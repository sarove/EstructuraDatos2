# Challenge 09 · Menú lateral desde un árbol N-ario

**Estudiante:** Salvador Rodriguez Velasco
**Asignatura:** Estructuras de Datos y Algoritmos II, Universidad Autónoma de Occidente

Árbol N-ario de menús y submenús. Cada ítem tiene `title`, `link` y `component`. El menú lateral se dibuja imprimiendo el árbol con un componente recursivo (DFS), y las rutas de la aplicación también se generan recorriendo el árbol.

## Ejecución

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # pruebas del árbol
```

Requiere Node.js 20.19+ (recomendado 22 LTS). Ver `ESTUDIANTE.txt` y `docs/`.
