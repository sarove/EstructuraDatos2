--------------------------------------------------------------
 CONCEPTO: ÁRBOL N-ARIO
--------------------------------------------------------------
 Parte de un nodo raíz (el único sin padre). Cada nodo tiene un
 valor y una lista de hijos de cualquier tamaño. Los nodos sin
 hijos son hojas.

 Clase Nodo (como en la clase):
   valor, hijos[], agregarHijo(nodo), esHoja()
 Clase ArbolNario:
   dfs()        recorrido en profundidad (recursivo)     O(n)
   bfs()        recorrido por niveles (con una cola)      O(n)
   buscar()     primer nodo que cumple una condición      O(n)
   rutaHasta()  camino desde la raíz hasta un nodo        O(n)
   tamano(), altura(), hojas(), grado(), imprimir()

 Árbol de menús: 16 nodos, altura 3, 12 hojas.
   Menú principal (raíz)
   ├── Perfil
   ├── Mensajes
   ├── Configuración
   │   ├── Cuenta
   │   ├── Perfil público
   │   ├── Seguridad y privacidad
   │   │   ├── Verificación en dos pasos
   │   │   └── Sesiones activas
   │   ├── Contraseña
   │   └── Notificaciones
   ├── Ayuda
   │   ├── Preguntas frecuentes
   │   ├── Enviar un ticket
   │   └── Estado de la red
   └── Cerrar sesión

--------------------------------------------------------------
 CÓMO EJECUTAR
--------------------------------------------------------------
 Requisito: Node.js 20.19 o superior (recomendado 22 LTS) y npm.

   1) Abrir una terminal en la carpeta del proyecto
   2) npm install          (instala dependencias)
   3) npm run dev          (inicia el servidor de desarrollo)
   4) Abrir http://localhost:5173 en el navegador

 Otros comandos:
   npm test                (ejecuta las pruebas del árbol)
   npm run build           (genera la versión de producción en dist/)
   npm run preview         (sirve la versión de producción)
