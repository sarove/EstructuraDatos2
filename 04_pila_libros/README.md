# Challenge 04 · Pila de libros en React

**Estudiante:** Salvador Rodriguez Velasco
**Asignatura:** Estructuras de Datos y Algoritmos II, Universidad Autónoma de Occidente

Pila (Stack, LIFO) de libros con Nombre, ISBN, Autor y Editorial.

| Ruta | Pantalla |
|------|----------|
| `/` | Pila de libros impresa en pantalla (cima → base), con `pop`, `peek` y `print` |
| `/nuevo-libro` | Formulario para crear un libro y agregarlo con `push` |

## Ejecución

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # pruebas de la pila
```

Requiere Node.js 20.19+ (recomendado 22 LTS). Ver `ESTUDIANTE.txt` y `docs/`.
