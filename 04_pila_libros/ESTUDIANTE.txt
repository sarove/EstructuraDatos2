--------------------------------------------------------------
 ENUNCIADO
--------------------------------------------------------------
 1. Crear y manejar una nueva pila de libros. Cada libro debe
    tener Nombre, ISBN, Autor y Editorial.
 2. Llenar la pila con datos simulados (mock).
 3. Crear un proyecto nuevo en React e implementar una pantalla
    con un formulario para crear un libro y agregarlo a la pila.
 4. Imprimir la pila de libros en pantalla.

--------------------------------------------------------------
 CONCEPTO: PILA (LIFO - Last In, First Out)
--------------------------------------------------------------
 El último libro que se agrega (push) queda en la CIMA y es el
 primero que sale (pop). Métodos implementados (clase Stack):
   push(value)  agrega en la cima                     O(1)
   pop()        saca y retorna la cima (o null)       O(1)
   peek()       retorna la cima sin sacarla (o null)  O(1)
   isEmpty()    true si la pila está vacía            O(1)
   size()       cantidad de elementos                 O(1)
   print()      imprime de la cima a la base          O(n)

--------------------------------------------------------------
 CÓMO EJECUTAR
--------------------------------------------------------------
 Requisito: Node.js 20.19 o superior (recomendado 22 LTS) y npm.

   1) Abrir una terminal en la carpeta del proyecto
   2) npm install          (instala dependencias)
   3) npm run dev          (inicia el servidor de desarrollo)
   4) Abrir http://localhost:5173 en el navegador

 Otros comandos:
   npm test                (ejecuta las pruebas de la pila)
   npm run build           (genera la versión de producción en dist/)
   npm run preview         (sirve la versión de producción)
