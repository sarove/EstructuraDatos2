# Challenge 03 · Listas enlazadas en React

**Estudiante:** Salvador Rodriguez Velasco
**Asignatura:** Estructuras de Datos y Algoritmos II — Universidad Autónoma de Occidente

Proyecto React (Vite) con dos páginas:

| Ruta | Estructura | Caso de uso |
|------|-----------|-------------|
| `/lista-enlazada` | Lista enlazada simple (`Node`, `LinkedList`) | Reproductor que toca canciones en orden |
| `/lista-doblemente-enlazada` | Lista doblemente enlazada (`DoublyNode`, `DoublyLinkedList`) | Historial del navegador con Atrás / Adelante |

## Ejecución

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # pruebas de las estructuras
```

Requiere Node.js 20.19+ (recomendado 22 LTS).

Ver `ESTUDIANTE.txt` para el detalle de la entrega.
