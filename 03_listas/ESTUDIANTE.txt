 ENUNCIADO
--------------------------------------------------------------
 1. Implementar una lista enlazada para reproducir canciones en
    orden. Llenar la lista con datos simulados (mock).
 2. Implementar una lista doblemente enlazada para navegar hacia
    atrás y hacia adelante entre páginas visitadas en el
    navegador. Llenar la lista con datos falsos (fake).
 3. Crear un proyecto en React con 2 páginas nuevas: lista
    enlazada y lista doblemente enlazada.
 4. Usar las listas implementadas en cada página. Recorrer las
    listas usando botones dentro de las páginas.

--------------------------------------------------------------
 CÓMO EJECUTAR
--------------------------------------------------------------
 Requisito: Node.js 20.19 o superior (recomendado 22 LTS) y npm.

   1) Abrir una terminal en la carpeta del proyecto
   2) npm install          (instala dependencias)
   3) npm run dev          (inicia el servidor de desarrollo)
   4) Abrir http://localhost:5173 en el navegador

 Otros comandos:
   npm test                (ejecuta las pruebas de las listas)
   npm run build           (genera la versión de producción en dist/)
   npm run preview         (sirve la versión de producción)
