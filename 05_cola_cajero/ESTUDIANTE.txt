 ENUNCIADO
--------------------------------------------------------------
 1. Crear y manejar una nueva cola de personas en un cajero
    automático. Cada persona debe tener nombre, monto a retirar
    y una fecha de llegada aleatoria asignada por el sistema.
 2. Llenar la cola con datos simulados (mock).
 3. Crear un proyecto nuevo en React e implementar una pantalla
    con un formulario para crear una persona y agregarla a la cola.
 4. Imprimir la cola en pantalla según la fecha de llegada.

--------------------------------------------------------------
 CONCEPTO: COLA (FIFO - First In, First Out)
--------------------------------------------------------------
 La primera persona en llegar es la primera en ser atendida.
 Métodos implementados (clase Queue):
   enqueue(item)  agrega al final                       O(1)
   dequeue()      saca y retorna el frente (o null)     O(n) por shift()
   peek()         retorna el frente sin sacarlo         O(1)
   size()         cantidad de elementos                 O(1)
   isEmpty()      true si la cola está vacía            O(1)
   print()        imprime del frente al final           O(n)

 AtmQueue extiende Queue: como la fecha de llegada es aleatoria,
 enqueue ubica a cada persona en su posición cronológica (O(n)).
 Así el frente siempre es quien llegó primero y la cola queda
 impresa según la fecha de llegada.

--------------------------------------------------------------
 CÓMO EJECUTAR
--------------------------------------------------------------
 Requisito: Node.js 20.19 o superior (recomendado 22 LTS) y npm.

   1) Abrir una terminal en la carpeta del proyecto
   2) npm install          (instala dependencias)
   3) npm run dev          (inicia el servidor de desarrollo)
   4) Abrir http://localhost:5173 en el navegador

 Otros comandos:
   npm test                (ejecuta las pruebas de la cola)
   npm run build           (genera la versión de producción en dist/)
   npm run preview         (sirve la versión de producción)
